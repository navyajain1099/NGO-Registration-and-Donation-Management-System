1. Introduction

1.1 Project Overview

The NGO Registration and Donation Management System is a secure, web-based platform designed to bridge the gap between donors and non-governmental organizations. It provides a seamless interface for users to register, manage their profiles, and make secure donations. Simultaneously, it empowers administrators with tools to oversee user data, track financial inflows, and generate analytical reports.

1.2 Problem Statement

Traditional donation systems often suffer from a lack of transparency and inefficient record-keeping. Donors rarely have visibility into their past contributions, and NGOs struggle to maintain consolidated lists of donors and payments. This project aims to solve these issues by automating the entire workflow—from registration to payment verification.

1.3 Objectives

  • Transparency: Provide donors with a history of their contributions.
  • Security: Ensure all payments are verified using cryptographic signatures (HMAC SHA256).
  • Efficiency: Enable real-time tracking of funds for administrators.
  • Scalability: Built using a modular MERN-style architecture (using SQLite).

3. Key Features

3.1 Genuine Payment Verification

Unlike simple implementations that trust the frontend, this system performs backend verification. When a payment is completed, Razorpay sends a signature. The backend independently recalculates this signature using the Secret Key to verify authenticity.

const hmac = crypto.createHmac('sha256', process.env.RAZORPAY_KEY_SECRET); hmac.update(order_id + "|" + payment_id); if (hmac.digest('hex') === signature) { // Payment Verified Successfully }

3.2 Admin Dashboard

The admin panel provides a comprehensive view of the system's health. Features include:

  • Total User Registry: View all registered members.
  • Financial Overview: Aggregated view of total funds raised.
  • Data Export: Capability to download reports as CSV files.

3.3 User Experience

Users have a dedicated dashboard where they can donate via a secure popup and view their complete donation history with status indicators (Success/Pending).
